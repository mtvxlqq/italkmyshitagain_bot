# italkmyshitagain_bot

Бот оформляет и публикует посты в канал.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Добавь бота **администратором** канала с правом «Публикация сообщений».
3. Напиши боту `/start` (иначе он не сможет присылать тебе уведомления).
4. Настрой и запусти:

```bash
cp .env.example .env        # впиши BOT_TOKEN, ADMIN_IDS, CHANNEL
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

## Как сделать пост

Отправь боту фото, видео или альбом (до 10 штук, фото и видео можно смешивать) с подписью:

```
Заголовок на картинку
Текст поста, можно с жирным, курсивом, ссылками и эмодзи.
```

- На все фото и видео накладывается оверлей из `assets/overlay.png`. Заголовок (первая строка
  подписи) ставится только на первый файл: белым, заглавными, с мягкой тенью. Длинный
  заголовок переносится на 2–3 строки. Эмодзи из заголовка убираются: в шрифте их нет.
- Формат выбирается по кадру, лишнее обрезается по центру:
  - вертикальные → 3:4 (1080×1440);
  - почти квадратные (шире не более чем в 1,15 раза) → 1:1 (1080×1080);
  - горизонтальные → 4:3 (1440×1080) или 16:9 (1920×1080), какой ближе.
- Видео перекодируется в H.264 с тем же оверлеем. Бот может скачать файл только до 20 МБ
  (ограничение Bot API), а итоговое видео укладывается в 50 МБ.
- Заголовок остаётся первой строкой поста жирным шрифтом, остальной текст — как был.
  В конце добавляется жирная ссылка на канал.
- Бот присылает превью и кнопки: **Опубликовать**, **Отложить** или **Удалить черновик**.
- Если текст длиннее 1024 символов (это лимит подписи в Telegram), он уходит
  отдельным сообщением сразу под постом.

## Музыка

Пришли трек (файлом-музыкой, до 20 МБ) после поста — бот возьмёт последний черновик
и спросит таймкод:

- `1:05` — 30 секунд начиная с 1:05;
- `1:05-1:40` — конкретный отрывок (до 5 минут).

Фото с оверлеем и заголовком превращается в видео с этим отрывком (с плавным появлением
и затуханием звука). В альбоме видео становится первое фото, остальные остаются как есть.
Чтобы взять другой отрывок, пришли трек ещё раз — видео пересоберётся из исходного фото.
На посты, которые начинаются с видео, музыка не накладывается.

## Отложенные посты

После «Отложить» пришли время: `18:30`, `завтра 10:00`, `25.09 19:00`, `+2ч`. Можно нажать
одну из готовых кнопок. `/queue` показывает очередь: каждый пост можно выложить сразу или
снять с публикации. Очередь хранится в `bot.db` и переживает перезапуск бота.

## Подписчики и статистика

- Пока подписчиков меньше 100, бот пишет о каждом новом подписчике.
- Когда их становится 100, бот один раз поздравляет, а дальше каждый день в `STATS_TIME`
  присылает статистику: сколько подписчиков, сколько пришло и ушло, сколько постов вышло.
- `/stats` показывает статистику за сегодня в любой момент.

Bot API не отдаёт просмотры и охват постов. Их можно посмотреть только во встроенной
статистике Telegram.

## Оверлей

`assets/overlay.png` экспортирован без прозрачности: под оверлеем коричневая заглушка вместо
фото. При запуске бот убирает заглушку, оставляет зерно (светлое и тёмное), пыль, полосы и нижний градиент, стирает
надпись «ВАШ ТЕКСТ» и сохраняет результат в `assets/overlay_clean.png`. Для кадров 3:4 оверлей
растягивается по высоте, а для 4:3 и 16:9 расширяется повтором середины (края и пятно
в углу не искажаются). Если заменить `overlay.png`, файл пересоберётся сам. Лучше всего
экспортировать оверлей в PNG с прозрачным фоном, тогда бот возьмёт его как есть.
