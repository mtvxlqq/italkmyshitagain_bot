# italkmyshitagain_bot

Бот оформляет и публикует посты в канал.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Добавь бота **администратором** канала с правом «Публикация сообщений».
3. Напиши боту `/start` (иначе он не сможет присылать тебе уведомления).
4. Настрой и запусти:

```bash
cp .env.example .env        # впиши BOT_TOKEN, ADMIN_IDS, CHANNEL
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

## Как сделать пост

Отправь боту фото, видео или альбом (до 10 штук, фото и видео можно смешивать) с подписью:

```
Заголовок на картинку
Текст поста, можно с жирным, курсивом, ссылками и эмодзи.
```

Бот сразу присылает превью в режиме **Новость** (или **Цитата**, если первая строка в кавычках
либо оформлена цитатой Telegram). Под превью — кнопки, которыми можно сменить оформление,
бот перерисует пост:

| Режим | Как выглядит |
|---|---|
| 📰 Новость | 1080×1350: фото в рамке, «■ НОВОСТИ», заголовок, «ЧИТАЙ В ПОСТЕ →» |
| 📣 Анонс | 1080×1080: фото слева растворяется в фоне, карточка «?», «■ АНОНС», заголовок по центру, плашка с артистом |
| 💿 Релизы | 1080×1080: «ЭТИ РЕЛИЗЫ ВЫШЛИ СЕГОДНЯ» и до трёх обложек — первые фото альбома (первое — по центру, крупнее) |
| 💬 Цитата | 1080×1080: затемнённое чёрно-белое фото, «■ ЦИТАТА», текст в «ёлочках», автор |
| 🖼 Без оверлея | фото и видео только обрезаются под формат кадра |

- **Красные слова.** Слова первой строки, выделенные в подписи *курсивом* или подчёркиванием,
  на карточке будут красными (в тексте поста это выделение не сохраняется). Если ничего не выделено,
  красным становится конец заголовка: в анонсе — вторая половина слов, в новости — последняя
  половина.
- **Артист и автор.** В анонсе и цитате хвост первой строки после длинного тире
  (`Новый альбом на след неделе — 9mice`, `«Текст» — Kai Angel`) уходит в плашку с артистом /
  подпись автора.
- Длинный заголовок переносится на несколько строк и уменьшается, чтобы влезть в шаблон.
  Популярные эмодзи (25 штук из `assets/emoji/`) рисуются в заголовке в стиле Apple,
  остальные убираются. Чтобы добавить эмодзи, положи в папку PNG 96×96 с именем по коду
  символа (`1f602.png` = 😂).
- Шаблон получает только первый файл (в релизах — первые три фото), остальные файлы альбома
  идут без оформления. Формат для них выбирается по кадру: вертикальные → 3:4, почти
  квадратные → 1:1, горизонтальные → 4:3 или 16:9.
- Видео тоже можно оформить (кроме релизов): кадр встаёт в окно шаблона, сверху — тот же слой,
  что и у фото. Бот может скачать файл только до 20 МБ (ограничение Bot API), итоговое видео
  укладывается в 50 МБ.
- В шапке карточек — аватарка и имя канала: бот берёт их из Telegram при запуске
  (если не получилось — `assets/avatar.png`). Шрифты — Unbounded и Oswald из `assets/fonts/`.
- Заголовок остаётся первой строкой поста жирным шрифтом, остальной текст — как был.
  В конце добавляется жирная ссылка на канал.
- Бот присылает превью и кнопки: **Опубликовать**, **Отложить** или **Удалить черновик**.
- Если текст длиннее 1024 символов (это лимит подписи в Telegram), он уходит
  отдельным сообщением сразу под постом.

## Музыка

Пришли трек (файлом-музыкой, до 20 МБ) после поста — бот возьмёт последний черновик
и спросит таймкод:

- `1:05` — 30 секунд начиная с 1:05;
- `1:05-1:40` — конкретный отрывок (до 5 минут).

Карточка поста превращается в видео с этим отрывком (с плавным появлением и затуханием
звука). В альбоме видео становится первый файл, остальные остаются как есть. Чтобы взять
другой отрывок, пришли трек ещё раз — видео пересоберётся из исходных фото. Смена оформления
после этого уберёт музыку. На посты, которые начинаются с видео, музыка не накладывается.

## Отложенные посты

После «Отложить» пришли время: `18:30`, `завтра 10:00`, `25.09 19:00`, `+2ч`. Можно нажать
одну из готовых кнопок. `/queue` показывает очередь: каждый пост можно выложить сразу или
снять с публикации. Очередь хранится в `bot.db` и переживает перезапуск бота.

## Подписчики и статистика

- Пока подписчиков меньше 100, бот пишет о каждом новом подписчике.
- Когда их становится 100, бот один раз поздравляет, а дальше каждый день в `STATS_TIME`
  присылает статистику: сколько подписчиков, сколько пришло и ушло, сколько постов вышло.
- `/stats` показывает статистику за сегодня в любой момент.

Bot API не отдаёт просмотры и охват постов. Их можно посмотреть только во встроенной
статистике Telegram.
